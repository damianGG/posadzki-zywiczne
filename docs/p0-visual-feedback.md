# P0 — uwagi wizualne właściciela
- Strona główna: zdjęcia wszystkich pięciu zastosowań przemysłowych. W pierwszej kolejności wybór projektu po tytule; fallback to dotychczasowe materiały ilustracyjne produkcji, gastronomii i hali, jawnie oznaczone poglądowo. Nie utożsamiać z własną realizacją ani dowodem klasy ESD/cleanroom. Docelowo zastąpić osobnymi, potwierdzonymi kadrami.
- Balkony i tarasy: układ analogiczny do garaży, zdjęcia, ceny i ograniczenia, nawigacja, formularz z wybranym wykończeniem. Nie wprowadzamy niepotwierdzonych stawek. Dane lokalizacji zdjęcia balkonu są sprzeczne w archiwalnym JSON; podpis bez miasta do wyjaśnienia.
- Kamienny dywan: jasna ciepła kolorystyka, kontrastowy przycisk, zachowany lokalny gradient wyłącznie na podpisie fotografii.
- Motyw marki: trzy linie warstw, kość słoniowa i miedź #895238; wspólny CSS bez nowych zależności. Sprawdzić kontrast, sticky menu, mobile, wszystkie fotografie Cloudinary i CTA przed merge.

## Korekta palety po kolejnej uwadze właściciela
Usunięto miedź, brązy i beże z identyfikacji UI. Kierunek neutralna biel, jasna szarość, grafit, mały akcent #00D664 (inspiracja dawną identyfikacją Netguru). Zieleń w motywie warstw, drobnych detalach, aktywnym kroku formularza i głównym CTA w nagłówku; pozostałe CTA grafitowe. Ciemniejszy #007A3D dla czytelnego tekstu i ikon. Jasne powierzchnie kamiennego dywanu pozostają. Do sprawdzenia w preview: kontrast, style przycisków i widoczność akcentów.
